========================================================
ROOT CAUSES SUMMARY
========================================================

Issue #1: Parser Scope Limitation (HIGH)
────────────────────────────────────────────────────
Component: MaturityDescriptionParser
Severity: HIGH
Impact: Amortized bonds with simple inline format cannot be processed
Affected: Fixed-frequency amortized bonds (annual, monthly, etc.)
Tests Blocked: TEST 5, 6, (7, 8 untested)

Example:
- "31/12/2030 (20% each year)" → REJECTED
- "31/12/2027 (10% quarterly)" → REJECTED
- But "9/11/2024 to 9/11/2033 (10% each year)" → ACCEPTED
- And "26-09-2031 (2.5% on Each IP till 2027)" → ACCEPTED

Root Cause:
The regex patterns in MaturityDescriptionParserImpl don't match inline format.
The parser expects explicit "to" keyword for fixed-frequency amortization.

────────────────────────────────────────────────────
Component: AccruedInterestService

Impact: Over-calculates accrued interest for bonds settled after repayment


========================================================
TEST FAILURE ROOT CAUSE: Integration Test
========================================================

Test: calculatesYtmUsingRealServicesForStagedAmortizationBond()

Expected: 10.04%
Actual: 10.06%

Why It's Not a Calculation Bug:

1. Test Setup (hardcoded constant):
   static final LocalDate CALCULATION_DATE = LocalDate.of(2026, 9, 3);

2. Actual Execution (uses LocalDate.now()):
   LocalDate calculationDate = LocalDate.now(); // = 2026-09-07

3. Result:
   - Settlement date moved 4 days forward
   - First coupon now 19 days away (instead of 23)
   - All future payments are in nearer term
   - Same total payments, but sooner
   - → Higher effective return (YTM)
   - → 10.04% (for 2026-09-03) becomes 10.06% (for 2026-09-07)

Mathematical Correctness:
✓ 10.04% is the CORRECT YTM for settlement 2026-09-03
✓ 10.06% is the CORRECT YTM for settlement 2026-09-07
✓ The 2-basis-point difference is expected and correct

The Test Doesn't Fail Because of Bad Math - It Fails Because the Test
Assumption (calculation date = 2026-09-03) Doesn't Match Implementation
(calculation date = TODAY).
